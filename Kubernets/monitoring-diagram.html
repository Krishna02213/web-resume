    Read the gaps, too.
    These observations come from this folder, not from a running cluster.
    Metrics are self-only
    The only scrape target is localhost:9090. These manifests do not collect application or Kubernetes node metrics. Alloy is configured only for logs here.
    Loki is not in Grafana yet
    Local Grafana provisions only Prometheus. Loki receives logs, but no Loki data source is provisioned. No dashboards are included.
    Two Secrets are referenced
    grafana-cloud must supply a token file for Prometheus. grafana-cloud-logs must contain key token for Alloy. Neither Secret is defined here.
    Local data is temporary
    All four workloads use emptyDir storage. No PVCs are defined. The three Services are ClusterIP; no public UI route is declared.
